Boundary Layer Growth Posterior Approximation Model Work Flow 

So i Will start with the physical factors that affect the growth: Reynolds num, Mach Num, and temp 
	this means 3 variables and there for 3 coeef i have to approximate 
	They will be A, B, and C 

so the equation would look like this: 
	bl_growth = A * Re + B * MachNum + C * Temp

A, B, and C will be my hyper priors 



priors (A, B, C) + likelihood = posterior of bl_growth 

the likelihood would be the error between true pressure data (made up with true bl values etc) and a pt data that is generated by the bl_growth = A * Re + B * MachNum + C * Temp, along with the same values for the other params (combustion end, cf etc) 


so plan right now 
as i create synthetic pressure data with "true" values of Bl and bl growth etc 
and compare that predicted the calculated BL_grwoth and the true values for the other params

whats next is actually calculating this bl_growth
A,B,C make sense they will be found using MCMC, but what im thinking about is what values do I used for 
	Re,M,T and from where 
I have two options:
The 1st is that I get the values for Re,M,T from the "true" case and I keep those values static and just sample/change coeffs
The 2nd is that I get the Re,M,T values from every single forward model run so each respective guess of A,B,C will have its own Re,M,T. 

The 2nd option seems like the better option its more physically realistic because if i am changing the boundary layer growth, the flow should also be changing. There is more inference so it may be harder to identify

Then, i run into the issue of actually getting the data. Because in order to get the values of Re,M,T i need to run the forward solver with an already existing bl_growth, and if I am using an existing bl_growth, the Re,M,T will not be accurate for the calculated bl_growth.
	I also thought that i could by solve bl_growth in my forward model, but you come into the issue that the data you 
	get is affected by bl_growth. and you cant solve something that needs bl_growth without a prescribed bl_growth
